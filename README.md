# Mai Parent Coaching Website

Website for Mai - Child Psychologist & Parent Coach, featuring consultation bookings, digital products & parenting guides, video courses with Bunny Stream integration, blog, community hub, and admin management.

---

## 🚀 Quick Start

To run the project locally:

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

For more detailed instructions, see [docs/QUICK_START.md](file:///d:/Cursor/Mai_Website/docs/QUICK_START.md).
