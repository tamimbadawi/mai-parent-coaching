# Mobile App — Next Steps

## Implementation Priority & Prerequisites

> [!IMPORTANT]
> The mobile app is **lower priority** relative to the Booking System and Payments. The web application must be functionally solid (real booking persistence and admin workflows at minimum) before wrapping into mobile containers. Wrapping an unwired web flow simply duplicates flaws across more platforms.

---

## Execution Guidelines

When mobile app development begins:
1. Follow the **Six-Step Build Plan** defined in [`decisions.md`](file:///d:/Cursor/Mai_Website/project-plan/mobile-app/decisions.md) in strict sequence.
2. Complete and verify each step individually before advancing to the next.
3. Do not batch multiple build steps together even if offered.
